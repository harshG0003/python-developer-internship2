# Week 2 – Data Structures & File Handling

## Internship
**Skill Nexis – Python Developer Internship**

## Overview
This week, I practised Python data structures, file handling, JSON, CSV, and exception handling through three assignments and one mini-project.

## Assignments

### 1. Contact Book
- Add, search, update, and delete contacts.
- Uses a Python dictionary to manage contacts.
- Uses JSON to save contacts permanently.

**Files:** `assignment1_contact_book.py`, `contacts.json`

### 2. Word Counter
- Reads text from a file.
- Counts words, lines, and characters.
- Handles a missing text file.

**Files:** `assignment2_word_counter.py`, `sample.txt`

### 3. JSON File Reader
- Reads student records from a JSON file.
- Displays student names, roll numbers, and marks.
- Handles invalid JSON data and missing files.

**Files:** `assignment3_json_reader.py`, `students.json`

## Mini-Project: Student Management System
- Add student records.
- Search students by roll number.
- Delete student records.
- Display all students.
- Save records permanently in a CSV file.

**Files:** `student_management_system.py`, `students.csv`

## Concepts Learned
- Lists and dictionaries
- Functions and loops
- Reading and writing files
- JSON and CSV handling
- Exception handling
- CRUD operations
- Permanent data storage

## How to Run
1. Install Python.
2. Open the `Week 2` folder in VS Code.
3. Run the required Python file in the terminal.
4. Keep the associated data files in the same folder.

## Learning Outcome
I practised organizing data with Python dictionaries and working with text, JSON, and CSV files. I also learned how to build simple programs that save and retrieve data between runs.
